# 🕷️ Spider-Man Multiverse – Catálogo de Filmes Interativo

Este projeto é uma **interface web imersiva e animada**, desenvolvida como um desafio para a plataforma **DIO**. O site funciona como um catálogo que explora os filmes do **Homem-Aranha**, organizados pelos três atores que interpretaram o herói nos cinemas: **Tobey Maguire, Andrew Garfield e Tom Holland**. O foco do projeto foi a criação de uma experiência de usuário visualmente rica, utilizando **HTML, CSS com animações 3D e JavaScript puro** para interatividade.

## 💡 Sobre o projeto

A aplicação apresenta uma jornada pelo multiverso do Homem-Aranha, dividida em duas seções principais:

- **Página Inicial:** Um menu principal com um **carrossel 3D interativo**, onde cada face representa um dos atores. O usuário pode girar o carrossel para selecionar o universo do Homem-Aranha que deseja explorar. Animações de hover e a troca dinâmica do plano de fundo criam uma experiência fluida e envolvente.

- **Páginas Internas:** Para cada ator, há uma série de páginas dedicadas a cada um de seus filmes. Essas páginas contêm informações detalhadas como **sinopse, ano, diretor, um link para o trailer** e uma **galeria de imagens**. Uma navegação vertical permite alternar facilmente entre os filmes de um mesmo ator.

---

## ⚙️ Funcionalidades principais

- 🕷️ **Carrossel 3D Interativo** na página inicial para selecionar o ator.
- 🎨 **Animações de Hover** nos cards, com efeitos de escala, sombra e alteração do background da página.
- 🖱️ **Controles de navegação** para girar o carrossel manualmente.
- 🎬 **Páginas de detalhes** para cada filme, com informações como sinopse, ano e direção.
- 🖼️ **Galeria de imagens** com efeito lightbox utilizando a biblioteca Fancybox.
- 🎥 **Link direto para o trailer** de cada filme no YouTube.
- 🧭 **Navegação vertical** nas páginas internas para pular entre os filmes de um mesmo ator.
- 🕸️ **Design temático e imersivo**, com fontes, ícones e planos de fundo personalizados para cada universo do herói.

## 🚀 Tecnologias e ferramentas utilizadas

- **JavaScript (ES6+)**
  - Manipulação do **DOM** para a lógica do carrossel 3D e animações.
  - Gerenciamento de **eventos de mouse** (click, mouseenter, mouseleave).
  - Lógica para alternar classes e estilos de forma dinâmica, sem frameworks.

- **HTML5**
  - Estruturação semântica da página inicial e das páginas internas de filmes.
  - Links de navegação entre as diferentes seções do site.

- **CSS3**
  - **Animações e transições** complexas para o carrossel e efeitos de hover.
  - Uso de **Flexbox** para a organização dos layouts.
  - Propriedade **`perspective`** e **`transform`** para criar o efeito 3D.
  - **Variáveis CSS** para manter um tema de cores consistente (`--primary-color`).
  - Estilização de componentes como botões, cards, e galerias.

- **FancyApps (Fancybox)**
  - Biblioteca externa utilizada para criar a galeria de imagens com visualização em lightbox.

- **Google Fonts**
  - Utilização da fonte **Poppins** para a tipografia do projeto.
